# 勤怠管理システム
## 概要

C++のGUIシステム理解の為に色々な機能を確かめ、行えるシステムを作成するため、自身なりの勤怠管理システムを作成。

```text
言語 C++

GUIライブラリ wxWidgets

データベース PostgreSQL

DB管理ツール pgAdmin4

開発環境 VsCode/ Git Bash(MSYS2/UCRT64)
```

## 主な機能

### ログイン機能

```mermaid
graph TD
A[ログイン画面 LoginPanel.cpp] --> B{ログイン認証}
B -- 成功 --> C[出退勤入力画面に移動 HomePanel.cpp]
B -- 失敗 --> D[エラーメッセージ表示]
```

### 出退勤入力機能

```mermaid
graph TD
A[出退勤入力画面 HomePanel.cpp] --> B{出勤ボタンか退勤ボタンを押す}
B -- ログイン状態 --> C{出勤と退勤ボタンが機能する。}
B -- ログアウト状態 --> D[ログイン画面に戻る]
C -- 「出勤」ボタンを押す。 --> E[勤怠履歴画面に出勤時間が保存される]
C -- 「退勤」ボタンを押す。 --> F{休暇申請が来ているか。}
F -- 申請が提出されている --> G[退勤記録されない]
F -- 申請が提出されていない --> H[勤怠履歴画面に退勤時間が保存される]

```

### 勤怠履歴機能

#### 勤怠履歴表(HistoryPanel.cpp)
| ユーザー | 出勤 | 退勤 | 修正メッセージ | 休暇メッセージ | 残業メッセージ |
| :--- | :--- | :--- | :--- | :--- | :--- | 
| ユーザー名 | 出勤時間 | 退勤時間 | 修正理由 | 休暇理由 | 残業理由 |

### 勤怠修正機能

```mermaid
graph TD
A[勤怠修正画面 EditPanel.cpp] --> B{修正項目を記載し、ボタンを押す}
B -- ログアウトの状態 --> J[警告文が表示し、ログイン画面へ移動する]
B -- 出勤修正の場合 --> C{該当する日付に勤怠データがあるかの確認}
B -- 退勤修正の場合 --> D{該当する日付に出勤しているデータはあるのか確認}
C -- 該当するデータがある場合 --> E{修正メッセージを入れているのか確認}
C -- 該当するデータがない場合 --> E{修正メッセージを入れているのか確認}
D -- 出勤しているデータがある場合 --> E{修正メッセージを入れているのか確認}
D -- 出勤データがない場合 --> F[警告文が表示し、退勤修正ができない]
E -- 修正メッセージを記載している場合 --> G[勤怠履歴画面に修正内容に変更]
E -- 修正メッセージを記載していない場合 --> H[エラー文が表示し、修正内容を送ることができない]
E -- 出勤データがない場合 --> I[新規に出勤データと修正メッセージ共に勤怠履歴画面に登録]
```

### 休暇申請機能

```mermaid
graph TD
A[休暇申請画面 VacationPanel.cpp] --> B{ログイン状態の確認}
B -- ログアウト状態 --> C[休暇申請を登録できない]
B -- ログイン状態 --> D{日付を指定する}
D -- 指定日に出勤データがある場合 --> E[休暇申請は登録できない]
D -- 指定日に出勤データがない場合 --> G{休暇メッセージが記載しているか}
G -- 記載していない場合 --> H[警告文が表示し、休暇申請を行わない]
G -- 記載している場合 --> I[日付と休暇内容を勤怠履歴画面に登録する]
```

### 残業申請機能

```mermaid
graph TD
A[残業申請画面 OvertimePanel.cpp] --> B[残業申請ボタンを押す]
B[残業申請ボタンを押す] --> C{ログイン状態の確認}
C -- ログアウト状態 --> D[警告文が発生し、申請登録ができない]
C -- ログイン状態 --> E[残業日の指定日を見る]
E[残業日の指定日を見る] --> F{指定日に勤怠データがあるか確認}
F -- 勤怠データがない場合 --> G[エラー文を表示し、申請登録ができない]
F -- 勤怠データがある場合 --> H[申請メッセージの確認]
H[申請メッセージの確認] --> I{申請理由が記載されているか}
I -- 記載なし --> G[エラー文を表示し、申請登録ができない]
I -- 記載あり --> J[指定日に残業申請理由を勤怠履歴画面に記載する]
```

### ユーザー登録機能

```mermaid
graph TD
A[ユーザー登録画面 UserPanel.cpp] --> B[登録ボタンを押す]
B[登録ボタンを押す] --> C[ユーザー名を確認する]
C[ユーザー名を確認する] --> D{ユーザー名が記載されているか}
D -- 記載なし --> E[メッセージボックスを表示し、ユーザー名記載を促す]
D -- 記載あり --> F[パスワードを確認する]
F[パスワードを確認する] --> G{パスワードが記載されているか}
G -- 記載なし --> H[メッセージボックスを表示し、パスワード記載を促す]
G -- 記載あり --> I[ユーザー名とパスワードの値を確認する]
I[ユーザー名とパスワードの値を確認する] --> J{別ユーザーのユーザー名とパスワードの値を見る}
J -- ユーザー名とパスワードの値が同じ場合 --> K[メッセージボックスが表示し、ユーザー名とパスワードのどちらかの変更を促す]
J -- ユーザー名またはパスワードの値が違う場合 --> M[ユーザー名とパスワードがデータベースに保存する]
```

### ユーザー削除機能

```mermaid
graph TD
A[ユーザー登録画面 UserPanel.cpp] --> B[削除ボタンを押す]
B[削除ボタンを押す] --> C{ユーザー名確認}
C -- ユーザー名記載なし --> D[メッセージボックスを表示、ユーザー名記載を促す]
C -- ユーザー名記載あり --> E{パスワードの確認}
E -- パスワード記載なし --> G[メッセージボックスを表示、パスワード記載を促す]
E -- パスワードが間違いの場合 --> H[メッセージボックスを表示、ユーザー名かパスワードの値を変更を促す]
E -- ユーザー名とパスワードの一致 --> I[データベースのデータを削除する] 
```
